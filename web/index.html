When the lexicon has no answer, Decode can ask a Trendy proxy you run yourself. Model API keys stay on that computer — never in the browser.

Not connected — Decode uses the built-in lexicon and dictionary.

Advanced: running the proxy

On the computer that holds your model API key:

export TRENDY_PROXY_TOKEN=pick-a-long-secret
trendy serve --host 0.0.0.0 --port 8787

Then enter http://<that-computer’s-LAN-IP>:8787 and the same token above. Without --host the proxy only listens on the same computer (http://127.0.0.1:8787).

Community suggestions: when Decode is unsure you can suggest a definition. With a proxy set, suggestions are shared and can graduate into the community lexicon; without one, consensus is a same-device demo only. See docs/community-lexicon.md.

Decode checks the on-device slang lexicon first and may look up single words in Wiktionary or a free dictionary API. Live Decode (optional) only contacts your own proxy, only on misses. No API keys are stored in the browser. Digest settings stay on this device.
