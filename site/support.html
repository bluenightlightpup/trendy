Support

Help for the Trendy web app, iOS app, CLI and MCP server

Trendy decodes slang, texting abbreviations and meme trends, judgment-free. It works offline and needs no account.

Decode

Decode gave a weak or wrong answer

Answers marked Lower confidence (Pattern guess, Best guess, Dictionary) mean the term is not in the lexicon yet. Try a different spelling or just the key word. Report missing or wrong terms using the contact link below.

How fresh is the trend list?

Trend Radar refreshes the catalog once a day. The web app is republished with each refresh and picks up the newest copy whenever it’s online. The iOS app ships the catalog inside the app and is refreshed with app updates. The CLI uses the copy bundled when you installed it; reinstall to update.

Privacy

Does Trendy collect data?

No. See the privacy policy. The only optional network request is a single-word dictionary lookup. In the iOS app you can switch it off under You → Decode.

Apps

Install the web app on your phone

Open the web app. On iPhone, tap Share → Add to Home Screen in Safari. On Android, open Chrome’s menu and choose Install app or Add to Home screen. After the first visit it works offline.

Reset the app

iOS: You → Saved trends → Clear saved trends. Deleting the app removes all of its data.

Web app: unheart trends under You → Saved trends, or clear this site’s data in your browser settings to reset everything.

When is the iPhone app coming out?

Soon. It’s being prepared for the App Store. Until then, the web app has the same features and works on any phone.

CLI and MCP

Install the command line tool

With Python 3.10+, run pipx install git+https://github.com/bluenightlightpup/trendy (or use python3 -m pip install with the same URL). Then try trendy decode 67.

Connect Trendy to Cursor or Claude Desktop

Add {"mcpServers": {"trendy": {"command": "trendy-mcp"}}} to ~/.cursor/mcp.json or to Claude Desktop’s claude_desktop_config.json, then restart the app. If the client can’t find trendy-mcp, use the full path printed by which trendy-mcp (macOS/Linux) or where trendy-mcp (Windows). More options are in the README.
