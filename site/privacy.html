Privacy Policy

Effective October 6, 2026 · Covers the Trendy website, web app, iOS app, CLI and MCP server · Developer: bluenightlightpup

The short version

  • We collect no data. No accounts, sign-in, ads, analytics, tracking, cookies or third-party SDKs, anywhere.
  • Everything stays on your device. Saved trends and preferences are stored only on your phone or in your browser.
  • One optional kind of network request: decoding a single word can ask a public dictionary for extra meanings. Only that word is sent.

This website

These pages are plain static files. They set no cookies, use no analytics or trackers, and load no fonts, scripts or images from other sites. The small “What does 67 mean?” demo on the home page runs entirely in your browser.

The site is hosted on GitHub Pages. Like any web host, GitHub receives standard technical information such as your IP address when your browser requests a page, and handles it under the GitHub Privacy Statement. We don’t get access to visitor logs.

Web app (/app/)

The web app keeps your saved trends, the worlds you switch on or off, your digest setting and New here mode in your browser’s local storage on your device. It is never sent to us. Clearing your browser’s site data for Trendy removes it.

Once loaded, the trend catalog and slang lexicon work offline. For single-word queries the web app also looks the word up in a public dictionary; see Dictionary lookup below.

Live Decode (optional, off by default). Under You → Live Decode you can enter the address of a Trendy proxy that you run on your own computer. Only then, terms the lexicon can’t answer and any community suggestions you choose to submit (with a random ID created on your device) are sent to that proxy. We don’t operate any proxy and never receive this traffic. The proxy address and token are stored in your browser only.

iOS app

Trendy for iOS keeps the trends you save, the worlds you switch on or off, your digest setting, New here mode and the Dictionary lookups setting in iOS’s standard app storage (UserDefaults) on your device. This data is never sent to us or anyone else and is removed when you delete the app. Like other app data it may be included in your own iCloud or computer backups, which we cannot access.

Decode conversations are kept in memory only and are cleared when the app closes. Privacy, support and credits links open in Safari; websites you visit there have their own policies.

Optional dictionary lookup

For single-word queries (for example “rizz”, not “nah I’d win”), Trendy can fetch extra dictionary definitions:

  • What is sent: only the word you searched, over HTTPS. No account, device or advertising identifier, location or cookies. As with any internet request, the service can see your IP address.
  • Where it goes: the iOS app asks the Free Dictionary API (api.dictionaryapi.dev). The web app first asks Wiktionary (en.wiktionary.org, run by the Wikimedia Foundation) and may fall back to the Free Dictionary API. Both are independent public services. We don’t operate them, receive their logs or share anything else with them.
  • Turning it off: in the iOS app, go to You → Decode → Dictionary lookups, and Decode then works fully offline. The web app has no switch for this yet; if you’d rather not send single words, use the iOS app with lookups off, or the CLI.

Multi-word phrases are never sent. If a lookup fails or you’re offline, Trendy quietly shows its offline answer.

CLI and MCP server

The trendy command and the trendy-mcp server run on your own computer. They have no telemetry. Decoding, trend lookups and all four MCP tools read the bundled data and make no network requests. Two opt-in developer commands do use the network, and only when you run them: trendy radar run fetches public trend sources to refresh the catalog, and trendy serve (the Live Decode proxy) sends terms to the AI model provider whose API key you configure on that computer.

Children

Trendy does not collect personal information from anyone, including children. It explains some adult slang in plain, non-graphic language so parents and caregivers can understand it; swear words are masked.

Changes
