    CLI · MCP server · AI agents

    Let your AI agent decode slang too

    Trendy ships as a tiny, dependency-free Python command line tool and a local, read-only MCP server. Cursor, Claude Desktop and any MCP client can look up slang from the same lexicon. No API keys, no network calls.

    1. Install

    Needs Python 3.10+. Gives you the trendy and trendy-mcp commands.

    Terminal
    pipx install git+https://github.com/bluenightlightpup/trendy
# no pipx? use: python3 -m pip install …

    The package is called trendy-cli. A PyPI release is planned; until then, install straight from GitHub.

    2. Decode from your terminal

    Exit code 0 when found, 1 when there’s no match. Add --json for scripts.

    Terminal
    $ trendy decode 67
67  [slang]
short:   Gen Alpha / TikTok brainrot…
origin:  TikTok sounds (notably Skrilla…
age:     Gen Alpha — mostly kids/tweens…

$ trendy trends --min-heat 0.7
$ trendy radar status

    3. Add it to Cursor

    Put this in ~/.cursor/mcp.json (or .cursor/mcp.json in a project). Claude Desktop uses the same block in claude_desktop_config.json.

    ~/.cursor/mcp.json
    {
  "mcpServers": {
    "trendy": { "command": "trendy-mcp" }
  }
}

    Then ask your agent things like “what does aura farming mean?” or “what’s trending on TikTok right now?”

    Five read-only tools

    Local stdio only. No write tools, no network access, nothing to configure.

    • decode_termMeaning, origin and who says it for one term or phrase.
    • search_slangFind lexicon entries that match a word or topic.
    • get_trendsThe trend catalog with heat, lifecycle, world and age band.
    • radar_statusWhen Trend Radar last refreshed the catalog, and from which sources.
    • word_of_the_dayToday’s word (or any date’s), the same one the apps show.

    More setup options (uv, Windows, running from a checkout) are in the README on GitHub.

    Private by design

    Ask anything. Nobody’s watching.

    • No account, no tracking

      No sign-in, ads, analytics or cookies. Trendy doesn’t collect data, on this site or in its apps.

    • Stays on your device

      Saved trends and settings live on your phone or in your browser, never on a server.

    • Judgment-free answers

      Plain words for parents, teachers, writers and anyone who just saw “it’s giving” and needs answers.

    The one exception: decoding a single word can look it up in a public dictionary, and only that word is sent. Details are in the privacy policy.
